01. High-Level Security Architecture

  • Encryption runs locally on user device hardware.
  • Zero-knowledge architecture model: master passwords are never transmitted.
  • Cloud services handle cipher-text data exclusively.
  • Strict zero-recovery safeguard policy (user retains absolute sovereignty).

02. Cryptographic Engine & Primitives

Encryption Cipher

XChaCha20-Poly1305 via Google Tink library. Utilizes 256-bit keys and 192-bit nonces for high-speed authenticated encryption with integrity protection.

Key Derivation Function

PBKDF2 with HMAC-SHA256 with random per-user salt generation. Vault data operates on high iterations, while export packages scale up to ~310,000 iterations to block offline brute-forcing.

Brute-Force Mitigations

  • • Enforced artificial delays between failed authentication attempts.
  • • Escalating temporary lockout intervals for sequential failures.
  • • Monotonic clocks to prevent simple system time manipulation cheats.

In-Memory Hygiene

  • • Immediate character array wiping post-password consumption.
  • • Purging active derived keys upon vault manual/auto lock.
  • • Clearing decrypted internal memory caches on inactivity timeouts.
